# Service Query Results Alert Template

This folder contains the service query results alert template used in runZero.

## Files

- service-query-results.html

## Notes

- Copy and paste this template into a runZero alert template.
- When creating the alert template, select the runZero HTML template type.
- This template is designed for query rules that return `query.services` rows.
- Update wording/branding in the HTML file as needed for your environment.
